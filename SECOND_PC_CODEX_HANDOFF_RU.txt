Первое действие на новом ПК
---------------------------

1. Найди People Playground в Steam-библиотеках, включая дополнительные
   libraryfolders.vdf. Не угадывай путь и не меняй игровые DLL/exe.
2. Клонируй репозиторий в удобную рабочую папку:

   git clone https://github.com/ForCesCustom/PPG-Connect.git
   cd PPG-Connect
   git pull origin main

3. Проверь git status. Не удаляй и не добавляй в commit чужие локальные файлы.
4. Установи тот же готовый Connect пакет: полностью распакуй
   Releases/Connect-v0.1.41.zip в корень игры — туда, где лежит
   People Playground.exe. Разреши объединить BepInEx. Не заменяй exe игры,
   игровые DLL, steam_api DLL и чужие BepInEx-плагины.
5. Проверь, что итоговый файл существует:
   <GameRoot>\BepInEx\plugins\Connect\Connect.BepInEx.dll
6. Запускай игру через Steam. Если игра была открыта до установки, сначала
   закрой и открой её снова. Нажми F8 для панели Connect, F10 для диагностики.

После каждой реальной правки:

3. Сверь SHA-256 собранного Connect.BepInEx.dll и DLL в установленной папке.
4. Создавай новый release ZIP с новой версией, не перезаписывай старый ZIP.
5. Только затем git add конкретных файлов, commit и git push origin main.

Что уже реализовано
--------------------

- Steam Lobby/invite через существующий игровой Facepunch Steamworks context:
  Connect не вызывает Steam init/shutdown и не добавляет Steam DLL.
- Steam Relay transport, handshake, независимые цветные world-space cursors,
  host-authoritative grab leases, Tab-spawn через хост, post-start baseline и
  root Rigidbody2D snapshots.
- Хост ведёт игроков на выбранную карту; гость не может выбрать другую карту.
  Host panel показывает LOADING MAP / SYNCING / PLAYING / MAP FAILED.
- Runtime поставляется plug-and-play ZIP: BepInEx, Doorstop, Connect DLL,
  rounded icon, Workshop Companion и документация.
- Workshop Companion показывает понятную плашку и ссылку на GitHub, если
  runtime отсутствует или его версия не совпадает.
- Bot Mode UI, кнопки, выбранное пользователем число ботов, cursor visuals,
  names/IDs и lifecycle НЕЛЬЗЯ переписывать без отдельного запроса.
- В v0.1.40/0.1.41 внутренний bot AI заменён: BotWorldKnowledge,
  BotSpawnCatalog, BotMind, personality/mood/memory, interest map, bounded
  world scans, object classifier, utility goals, coordination claims, learned
  outcomes и multi-step plans.
- Human не является fallback для bot-spawn. Боты только наблюдают обычные
  существующие map objects, а grab/use/delete выполняют исключительно над
  зарегистрированными Connect roots на host; cleanup не удаляет вещи игроков.
- Архитектура описана в BOT_INTELLIGENCE.md.

Честность тестирования
----------------------

На основном ПК v0.1.41 успешно прошла compilation, BotBrain smoke tests,
Protocol smoke tests, InstallationHealth smoke tests, hash/ZIP verification
и была опубликована в GitHub. Полный двухаккаунтный Steam runtime-тест именно
v0.1.41 не утверждай выполненным, пока не проверишь его с двумя разными Steam
аккаунтами/устройствами.
